# Tō-ji figure sources

These six GLBs are original meshes and textures generated by [build_toji_figures.py](../../../Tools/build_toji_figures.py). Blender can open each GLB directly. To rebuild them and inspect both figures assembled, run this from the repository root with Blender on `PATH`:

```sh
blender -b -P Unreal/StupaPilgrimage/Tools/build_toji_figures.py -- --blend /tmp/toji-figures.blend
```

The pilgrim uses a body and four rigid, animated cloth pieces. Kūkai uses a single static posed mesh. Source axes are +Y forward and +Z up in Blender, in meters. GLB limb origins are the hips and shoulders. The optional Blender file restores those offsets for inspection. The Unreal map generator imports the pieces and retains hidden, non-colliding source actors tagged `Toji.Figure.<name>` so the map references their cooked materials and textures. The runtime uses the source mesh orientation and places the limbs at their joint pivots.
