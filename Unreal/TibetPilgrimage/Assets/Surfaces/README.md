# Surface scans

The shared 1K material set uses Poly Haven's original diffuse, DirectX normal and packed ambient occlusion / roughness / metalness images. The game uses them for local surface detail. Location-specific silhouettes and construction come from the level art. All nine files were checked against the hashes in the publisher's asset metadata.

| Use | Source |
| --- | --- |
| Rocky ground and grass | [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02) |
| Weathered wood | [Brown Planks 03](https://polyhaven.com/a/brown_planks_03) |
| Rendered wall | [Beige Wall 001](https://polyhaven.com/a/beige_wall_001) |

The textures are distributed under [CC0](https://polyhaven.com/license).
